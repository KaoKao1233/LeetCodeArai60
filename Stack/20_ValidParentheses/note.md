◆学び
・辞書をワード毎に改行することで見やすそう（,の位置は後ろと前どちらが良いのだろうか）　→　ワードの後ろに,をつけるのが推奨されていそう
・inputに括弧以外が入ってくる可能性を考えられていなかった。今回はsが括弧のみで構成されることが保証されていたが、チェックを実装するべきだった　→　なければ想定外なので単にdicに含まれるか検索だけでOK
・自分のコードはkeyを閉じカッコにしているのでinputが辞書に入ってなかったらそのまま開きカッコをstackに追加しているが、keyを開きカッコにすることでinputが想定外の場合、そもそもスタックに追加しない
・ブラケットを辞書検索する際に、辞書.keys()としていたが、これは書いた方が良いのだろうか？　→　特に良し悪しは無さそう
・空のシーケンスは偽として扱うことがPEP8で推奨されていたので、if len(open_brackets) != 0: return False は冗長的で推奨されない　→　return not open_brackets　でリストが空の場合はTrueを返す　と書くのが簡潔
